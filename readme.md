## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js 16+
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/leomatth/portfolio-leomatth.git

# Acesse o diretório
cd portfolio-leomatth

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
